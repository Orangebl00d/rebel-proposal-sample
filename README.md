# Rebel proposal sample

A sample of a personalized follow-up proposal page, the kind a rep builds from a recorded discovery call so each section answers something the prospect said on that call.

**Live page:** https://orangebl00d.github.io/rebel-proposal-sample/

- The client is fictional.
- Booking, email, and phone links are turned off, and the phone number is a fictional 555 number.
- The page asks search engines not to index or archive it.
